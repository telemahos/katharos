# ✨ Katharos — καθαριστής δίσκου για Mac

> ⚠️ **Αποποίηση ευθύνης:** Το Katharos διαγράφει αρχεία. Η χρήση γίνεται αποκλειστικά με δική σου ευθύνη. Ο δημιουργός δεν φέρει καμία ευθύνη για απώλεια δεδομένων ή οποιαδήποτε ζημιά. Κράτα πάντα αντίγραφο ασφαλείας (π.χ. Time Machine). Δες τα [LICENSE](LICENSE) και [DISCLAIMER.md](DISCLAIMER.md).

Εφαρμογή τύπου CleanMyMac, γραμμένη σε **Rust**. Σαρώνει παράλληλα σε όλους τους πυρήνες του επεξεργαστή, οπότε είναι πολύ γρήγορη ακόμη και σε μεγάλους δίσκους.

## Εγκατάσταση (μία φορά)

Άνοιξε το **Τερματικό** (⌘ + Space → «Terminal») και γράψε:

```
git clone https://github.com/telemahos/katharos.git
cd katharos
bash install.sh
```

Χωρίς git: πάτα **Code → Download ZIP** στη σελίδα του GitHub, αποσυμπίεσε στις Λήψεις και τρέξε `bash ~/Downloads/katharos-main/install.sh`.

Το script κάνει μόνο του όλα τα υπόλοιπα: εγκαθιστά τα εργαλεία της Apple και τη Rust αν λείπουν, μεταγλωττίζει την εφαρμογή για τον επεξεργαστή σου (Apple Silicon ή Intel), φτιάχνει το `Katharos.app` με εικονίδιο, το βάζει στις **Εφαρμογές** και το ανοίγει.

> Αν εμφανιστεί παράθυρο για «Command Line Tools», πάτα *Εγκατάσταση*, περίμενε να τελειώσει και ξανατρέξε την εντολή.

**Προτείνεται:** Ρυθμίσεις συστήματος → Απόρρητο & ασφάλεια → **Πλήρης πρόσβαση δίσκου** → πρόσθεσε το Katharos. Χωρίς αυτό, το macOS δεν επιτρέπει πρόσβαση σε συνημμένα Mail, Κάδο και ορισμένα cache.

## Τι σημαίνει το «Katharos»

Η λέξη **καθαρός** (αρχαία ελληνική *katharós*) σημαίνει *καθαρός, αγνός, διαυγής*. Η ίδια ρίζα υπάρχει στη λέξη *κάθαρση*, δηλαδή τον εξαγνισμό και την απελευθέρωση. Το όνομα περιγράφει ακριβώς τον σκοπό της εφαρμογής: να καθαρίζει τον δίσκο του Mac σου.

## Γλώσσες

Η εφαρμογή είναι διαθέσιμη σε **Ελληνικά, English, Deutsch, Español, Italiano, Français και 中文**.

- Την πρώτη φορά η εφαρμογή χρησιμοποιεί τη γλώσσα του Mac, αν είναι από τις παραπάνω.
- Μπορείς να αλλάξεις γλώσσα ανά πάσα στιγμή από το μενού κάτω αριστερά. Η αλλαγή γίνεται αμέσως.
- Τα κινεζικά χρησιμοποιούν τη γραμματοσειρά του συστήματος (PingFang), που περιλαμβάνεται στο macOS.

## Προστασία (antivirus)

Η ενότητα **Προστασία** έχει έξι καρτέλες:

- **Ιοί:** γρήγορη σάρωση, πλήρης σάρωση ή σάρωση φακέλου ή εξωτερικού δίσκου. Χρησιμοποιεί τη δωρεάν μηχανή [ClamAV](https://www.clamav.net) με βάση υπογραφών που ενημερώνεται καθημερινά. Τα αρχεία iCloud που δεν έχουν κατέβει παραλείπονται, ώστε η σάρωση να μην κατεβάζει τίποτα.
- **Καραντίνα:** τα μολυσμένα αρχεία μετακινούνται σε ασφαλή φάκελο και δεν μπορούν να εκτελεστούν. Μπορείς να τα επαναφέρεις ή να τα διαγράψεις οριστικά.
- **Αυτόματη εκκίνηση:** εμφανίζει τα LaunchAgents και LaunchDaemons και επισημαίνει τα ύποπτα: χωρίς υπογραφή, κρυφοί φάκελοι, προσωρινές θέσεις, scripts.
- **Υπογραφές εφαρμογών:** ελέγχει αν κάθε εφαρμογή είναι υπογεγραμμένη και επικυρωμένη από την Apple.
- **Επεκτάσεις browser:** Safari, Chrome, Brave, Edge, Firefox κ.ά., με προειδοποίηση για όσες έχουν πρόσβαση σε όλες τις σελίδες.
- **Κατάσταση ασφαλείας:** SIP, Gatekeeper, FileVault, Firewall, XProtect, αυτόματες ενημερώσεις, αυτόματη σύνδεση.

**Ενεργοποίηση σάρωσης ιών:**
1. Στην καρτέλα «Ιοί» πάτα **Εγκατάσταση ClamAV**. Θα ανοίξει το Τερματικό με την εντολή `brew install clamav`.
2. Πάτα **Ενημέρωση βάσης ιών**. Η πρώτη λήψη είναι μερικές εκατοντάδες MB.
3. Ξεκίνα σάρωση.

**Τι δεν είναι:** το Katharos είναι σαρωτής κατά παραγγελία, όχι antivirus πραγματικού χρόνου. Για προστασία πραγματικού χρόνου χρειάζεται ειδική άδεια της Apple, που δίνεται μόνο σε εταιρείες ασφαλείας. Συμπληρώνει το **XProtect**, το ενσωματωμένο antivirus της Apple που τρέχει ήδη σε κάθε Mac. Δεν το αντικαθιστά.

## Ασφάλεια

- Πριν από κάθε διαγραφή εμφανίζεται επιβεβαίωση.
- **Cache & logs** σβήνονται οριστικά, γιατί οι εφαρμογές τα ξαναδημιουργούν. Οι φάκελοι παραμένουν, αδειάζουν μόνο.
- **Αρχεία χρήστη** (μεγάλα, διπλότυπα, εφαρμογές, backups) πάνε στον **Κάδο**, απ' όπου επαναφέρονται.
- Ενσωματωμένο δίχτυ ασφαλείας: τίποτα έξω από τον φάκελό σου (εκτός από `.app` στις Εφαρμογές), ούτε φάκελοι όπως Έγγραφα, Library, Caches κ.λπ.
- Δεν αγγίζει εφαρμογές της Apple, cache του iCloud ή βιβλιοθήκες Φωτογραφιών/Μουσικής.

## Γρήγορος έλεγχος από το τερματικό

```
/Applications/Katharos.app/Contents/MacOS/katharos --scan
```
Δείχνει τι θα καθαριζόταν, **χωρίς να σβήσει τίποτα**.

## Απεγκατάσταση του Katharos
Σύρε το `Katharos.app` από τις Εφαρμογές στον Κάδο.
